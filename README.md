# E-Commerce Sales Analysis using PostgreSQL

## 📌 Project Overview

This project analyzes an e-commerce dataset using PostgreSQL to understand customer behavior, order patterns, product performance, and sales.

The project focuses on solving real-world business questions using SQL.

## 🛠️ Tools Used

- PostgreSQL
- pgAdmin
- SQL

## 📊 Dataset

The dataset contains four main tables:

- `users`
- `orders`
- `products`
- `order_items`

These tables contain information about customers, orders, products, quantities, prices, and sales.

## 🔍 SQL Concepts Used

- SELECT
- WHERE
- ORDER BY
- GROUP BY
- HAVING
- Aggregate Functions
- INNER JOIN
- LEFT JOIN
- Subqueries
- CTEs
- Window Functions
- ROW_NUMBER()
- RANK()
- LAG()
- Date Functions

## 💼 Business Questions

The analysis answers questions such as:

- How many orders were placed by each customer?
- What is the total amount spent by each customer?
- What is the average order value?
- Which customers placed the most orders?
- Which products have the highest sales?
- Which product categories generate the most revenue?
- Which customers have never placed an order?
- Who are the top customers by total spending?
- What is the average order value for each customer?

## 📈 Key Analysis Areas

### Customer Analysis
- Order frequency

### Product Analysis
